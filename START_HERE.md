# 🚀 RUN MARS - SUPER SIMPLE

## Copy & Paste This (One Command Does Everything)

```bash
cd /home/kaab/Desktop/MARS-MIPS-main && bash mars.sh bubble_sort.asm
```

**That's it!** ✅

It will:
1. ✅ Compile everything
2. ✅ Run the program
3. ✅ Show complete analysis with colored heatmap
4. ✅ Display optimization recommendations

---

## What You'll See

Colored output showing:
- 🔴 RED instructions (executed most)
- 🟠 ORANGE instructions (frequent)
- 🟡 YELLOW instructions (moderate)
- 🟢 GREEN instructions (rare)

Plus:
- Big-O complexity estimate
- Performance metrics
- Memory analysis
- Suggestions
